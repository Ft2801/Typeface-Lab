# Security Policy

## Supported versions

Typeface Lab is a static web application. Security fixes are applied to the latest version available on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest `main` | Yes |
| Older releases | No |

## Reporting a vulnerability

Do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting for this repository:

[https://github.com/Ft2801/Typeface_Lab/security/advisories/new](https://github.com/Ft2801/Typeface_Lab/security/advisories/new)

Include:

- A description of the issue and its potential impact.
- Steps or a minimal proof of concept.
- The affected browser or environment.
- Any suggested mitigation, if available.

Reports will be reviewed as soon as practical. Please allow reasonable time for investigation and remediation before public disclosure.

## Scope

The project contains no backend, authentication system, database, or server-side code. Reports involving the application's HTML, CSS, JavaScript, manifest, or deployment configuration are in scope. Google Fonts infrastructure and GitHub Pages are third-party services and should be reported to their respective providers when the issue is not caused by Typeface Lab.
