# Changelog

## Version 1.0.0 - 2026-07-26

### Added

- Initial public version of Typeface Lab.
- Embedded alphabetical catalog of 1,947 Google Fonts families.
- Search, presets, and a progressively loaded A-Z specimen browser.
- Select Font controls for opening the responsive picker on desktop and mobile.
- Capability-aware controls generated from static variants and variable font axes.
- Live preview controls for text, size, line height, letter spacing, and alignment.
- Safe Google Fonts CSS2 request generation and Font Loading API verification.
- Persisted light and dark themes.
- Automatic framing and size correction for unusual catalog specimens.
- Dynamic links to the selected family on Google Fonts.
- SEO metadata, Open Graph and Twitter cards, sitemap, robots file, web manifest, and favicon set.
- Branch-based GitHub Pages support through `.nojekyll`.
